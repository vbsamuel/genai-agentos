# Controlled Development Sequence

1. Canonical types and schemas.
2. State and closure engine.
3. Security and governance core.
4. Durable idempotency, events, checkpoints, replay, and lineage.
5. HTTP/gRPC/WebSocket adapters.
6. Discovery, ownership, lifecycle, and reassignment.
7. Local model runtime and provider-neutral connectors.
8. RAG, agent, tools, approval, and workflow.
9. Self-SRE and assurance.
10. Legacy cutover and removal.

Each stage requires passing acceptance, falsification, resource, recovery, and closure gates before the next stage becomes authoritative.
