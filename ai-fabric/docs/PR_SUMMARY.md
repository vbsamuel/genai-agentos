# Pull Request Summary

This branch introduces the consumer-laptop-native `AI_Fabric_Microservices` foundation with one `ai_fabric` namespace and one integrated behavior-control, event-orchestration, event-flow, data-flow, transition-state, and governance kernel. It adds a Rust workspace, embedded durable state, deterministic transitions, integrity checks, bounded resources, idempotency, closure evidence, HTTP execution, CI gates, and a no-Redis/no-Celery migration plan.
