# Phase 2 Work Packages

## AF-P2-01 Durable idempotency and event log

Deliver tenant-scoped durable idempotency records, append-only events, consumer checkpoints, and outbox publication.

## AF-P2-02 Operation control APIs

Deliver lookup, cancellation, replay, closure verification, and bounded event subscription.

## AF-P2-03 gRPC surfaces

Deliver unary, client-streaming, server-streaming, and bidirectional adapters behind `FabricKernel`.

## AF-P2-04 WebSocket surface

Deliver authenticated upgrade, frame schema, bounded queues, heartbeat, idle expiry, reconnect, resume, replay, and cancellation.

## AF-P2-05 Certificate and workload identity

Deliver local certificate wallet, mTLS, workload/device identity, rotation, revocation, and evidence.

## AF-P2-06 AI execution adapters

Deliver local-model connector first, provider-neutral optional connectors second, with model registry, resource admission, streaming normalization, and closure.

## AF-P2-07 RAG and agent execution

Deliver source ingestion, retrieval, evidence manifests, bounded workflow loops, checkpoints, tools, approvals, and side-effect receipts.

## AF-P2-08 Self-SRE and assurance

Deliver invariant monitor, diagnosis, quarantine, owner reassignment, recovery, closure watchdog, and compliance evidence objects.
